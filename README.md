# 🕒 Cyber Dashboard 2.0

Uma interface moderna e responsiva que combina um relógio digital preciso com um widget de clima simulado, envoltos em uma estética Cyberpunk/Futurista com animações interativas de fundo.

## 🚀 Funcionalidades

- Relógio Digital: Exibição de horas, minutos e segundos em tempo real com formatação de dois dígitos.
- Calendário Dinâmico: Exibe o dia da semana e a data atual formatada.
- Widget de Clima: Simulação de busca de dados meteorológicos com feedback visual de "carregando" e atualização aleatória de estados.
- Digital Rain Background: Animação de fundo baseada em Canvas com quadrados cadentes e efeito de "glitch" aleatório.
- Design Responsivo: Adaptado para dispositivos móveis, tablets e desktops.

## 🛠️ Tecnologias Utilizadas

- HTML5: Estrutura semântica dos widgets.
- CSS3: Estilização avançada com variáveis, Grid/Flexbox e efeitos de Glassmorphism (blur).
- JavaScript (Vanilla): Lógica do relógio, manipulação do DOM e animação de partículas no Canvas.
